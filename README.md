ONLY Space:


Only Space is a game ,where you goal to climb up until you reach the moon,because there is a rocket ship which brings you back to earth.
This game is inspired by only up ,but the twist is ,that it is in low gravity.
This game was made by the gameengine :Godot v4.4

Guide:
    WASD: normal movment
    space: jump
    R:Slow mo ->if you use slow mo your character is actually a little bit slower
    Shift: Sprint


This game is only supported as a downloadable on Windows and linux.
